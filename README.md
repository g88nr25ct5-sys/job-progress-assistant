# 求职进度助手 · Job Progress Assistant

一个轻量、无需登录的求职记录工具。使用 Minimal Line Art、Soft Editorial 与 Warm Pastel 风格，让投递、面试与机会保持清晰可见。

**[在线体验 / Live Demo](https://g88nr25ct5-sys.github.io/job-progress-assistant/)**

## 功能

- **首页**：正在关注的岗位总数、累计投递岗位数、累计面试场次、累计收到过的 Offer，以及近期安排和当前投递阶段分布。
- **岗位**：添加、编辑、删除、阶段切换、心形收藏，并组合使用公司／岗位搜索、城市、状态和收藏筛选。
- **面试**：按轮次保存历史记录，分为即将进行与过往面试，并记录每轮问题、回答和复盘。
- **日程**：查看岗位截止日期、测评、面试和 Offer 回复安排。
- **简历**：按目标方向管理版本，上传与下载 PDF、DOC、DOCX 文件（最大 8MB）。
- **数据管理**：JSON 导入／导出与岗位 CSV 导出。

## 使用

直接访问上方 Live Demo，或下载仓库后用浏览器打开 `index.html`。不需要安装依赖、构建工具、在线字体或后端服务。

在线体验首次打开时为空白记录，可自行添加岗位。页面在手机、平板与桌面端使用响应式布局。

## 本地数据

岗位与简历元信息保存在浏览器的 localStorage；简历附件保存在 IndexedDB。项目不会把这些数据上传至服务器，也不提供跨设备自动同步。

- 换浏览器、设备或网址时，本地记录不会自动跟随。由本地文件切换到在线 demo 时，可先从设置导出 JSON，再在 demo 中导入。
- JSON 备份包含岗位、收藏、面试历史与简历元信息，**不包含简历附件本身**；附件请另外保留。
- 导入前请备份当前记录。清除浏览器站点数据会移除本地记录和附件。

## 累计统计与旧数据

已投递、Offer 记录使用历史标记，面试按 `interviewHistory` 中的轮次累计。同轮重复保存会更新已有记录；后续状态变化不会抹去历史。

旧记录只迁移实际存在的面试信息，不会补造此前轮次或恢复已经被覆盖的数据。

## 项目结构

```text
index.html   页面与内联 SVG
style.css    视觉样式与响应式布局
app.js       本地存储、岗位、面试、简历与导入导出逻辑
.nojekyll    GitHub Pages 静态发布标记
```

## 开发与部署

技术栈为原生 HTML、CSS、JavaScript，无运行时依赖。

JavaScript 语法检查：

```sh
node --check app.js
```

GitHub Pages 从 `main` 分支根目录发布；修改静态文件并推送后会自动更新。
